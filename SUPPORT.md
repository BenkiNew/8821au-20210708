# Support

## English

- Installation and usage questions: [Discussions Q&A](https://github.com/BenkiNew/8821au-20210708/discussions/categories/q-a).
- Reproducible bugs and hardware test reports: [Issues](https://github.com/BenkiNew/8821au-20210708/issues), using the appropriate template.
- Suspected vulnerabilities: the private channel in [SECURITY.md](SECURITY.md).
- Code and documentation contributions: [CONTRIBUTING.md](CONTRIBUTING.md).

Search existing reports first. Include the driver release/commit, distribution,
exact kernel, adapter USB ID and a small sanitized log excerpt. Distinguish
compile-only checks from real-device tests. Never include passwords, network
names, MAC/IP addresses or other personal data in public logs.

Support is maintained on a best-effort basis with no guaranteed response time.
See [validation](docs/VALIDATION.md) for dated tested configurations. Prefer the
in-kernel `rtw88` driver where it meets your needs.

## Українською

- Встановлення й використання: [Discussions Q&A](https://github.com/BenkiNew/8821au-20210708/discussions/categories/q-a).
- Відтворювані баги та звіти перевірки обладнання: [Issues](https://github.com/BenkiNew/8821au-20210708/issues), відповідний шаблон.
- Підозрювані вразливості: приватний канал у [SECURITY.md](SECURITY.md).
- Зміни коду та документації: [CONTRIBUTING.md](CONTRIBUTING.md).

Спочатку пошукайте наявні звіти. Додайте реліз/commit драйвера, дистрибутив,
точне ядро, USB ID адаптера та короткий очищений фрагмент логу. Відрізняйте
перевірку збірки від тесту на обладнанні. Не публікуйте паролі, назви мереж,
MAC/IP-адреси чи інші персональні дані.

Підтримка надається за можливості, без гарантованого строку відповіді.
Перевірені конфігурації й дати наведено в [таблиці](docs/VALIDATION.md).
Використовуйте вбудований `rtw88`, якщо він задовольняє ваші потреби.
